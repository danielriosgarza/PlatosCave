## F26 · DESIGN.md · Components

> **Review:** this sentence documents a specificity accident, not a decision. The wireframe's CSS is two layers, the rail-era layout plus an override block "adapted from idea_draft.png"; the rail, `.pc-shell` grid, `.pc-topic-link`, `.pc-course-row`, `.pc-topic-row`, the blueprint rail cell and `--pc-rail-width` are all dead. Flatten to one layer, then this document can state intent (primary padding 9 × 22, radius 24) instead of explaining the cascade. The counterproposal is that single layer. Outline actions use the sheet surface and a secondary-ink border. Plain and text buttons have no resting fill; link buttons add an underline. The default hover uses the soft surface; primary hover applies `brightness(.9)`, and outline buttons retain their sheet background. Disabled buttons reduce opacity to .55. Browser-native keyboard focus is retained.
